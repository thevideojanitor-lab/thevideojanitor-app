Implementation Architecture
Shared Utility
_shared/resend.ts
Single sendEmail() function. All edge functions import from here. One API key. One place to debug.
Send Strategy
Fire & forget
Emails never block the main response. Wrap in try/catch with console.error only — email failure never fails the business operation.
Template Engine
Inline HTML strings
No React Email or MJML — Deno edge functions use plain string templates. Simple, zero extra deps, fast cold start.
